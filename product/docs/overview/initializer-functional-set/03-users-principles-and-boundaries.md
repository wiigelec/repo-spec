## Status

Directional overview content.

## Intended users

The initializer is intended for maintainers, developers, reviewers, human and AI collaborators, and framework maintainers validating that the framework can initialize more than one independent product repository.

## Product principles

Governed creation, overview before plan, specifications before maintained behavior, exact-revision evidence, self-contained output, lifecycle honesty, framework and project separation, Git compatibility, determinism, and safe failure remain the guiding principles.

## Boundaries

The initializer must not invent product semantics, acceptance decisions, or release claims.
