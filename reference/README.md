# Reference Repository Skeleton

This directory is the isolated-copy reference repository.

It proves the framework can describe a minimal initialized repository, including:

- repository and product specifications
- derived repository and product projections
- generation and validation entry points
- isolated-copy portability checks
- minimal source behavior, tests, and correspondence records

The reference is intentionally small, but it still needs to show product intent, success conditions, constraints, and boundaries clearly enough for an independent session to recover the work without prior context.
